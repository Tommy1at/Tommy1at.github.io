Dominik C. Aspeck :: Vorstellung einiger Projekte

Diese Webseite stellt ausgewaehlte private, unternehmerische und vereinsbezogene Projekte vor. Die Beitraege werden in Markdown gepflegt und mit Jekyll als statische Webseite ausgegeben.

Ausgangspunkt war ein Projektauftrag von [Gerald](https://www.senarclens.eu/~gerald/): eine persoenliche GitHub-Seite unter Verwendung von Markdown und eines Jekyll-Themes zu erstellen.

Git dient der Versionsverwaltung. Ein GitHub-Actions-Workflow erstellt die Webseite und veroeffentlicht sie ueber GitHub Pages.

> Technologien: Markdown, Jekyll, Liquid, Ruby, Git, GitHub Actions, GitHub Pages.
